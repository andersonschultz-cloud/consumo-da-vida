# Validação Responsive v5

Correções realizadas:
- cabeçalho não é sticky em tablet/smartphone, evitando sobreposição durante a rolagem;
- menu mobile abre dentro do fluxo do documento e empurra o conteúdo, em vez de cobri-lo;
- grids principais passam para 2 ou 1 coluna conforme largura;
- Calculadora, Planejador e Simulador passam para uma coluna em smartphones;
- cards, gráficos, modais, inputs e botões respeitam a largura da viewport;
- tratamento de safe-area para aparelhos com notch;
- menu fecha ao navegar, pressionar ESC, girar a tela ou mudar de breakpoint.
